# Cloud CV engine milestone

Portable deterministic parsing/reconciliation, blinding, export and outline inference adapted from HyPlug commit c657d83b5e6a37b61e9cb929e066f0f08b1e8605. Reuses existing CV Studio rule modules and renderer (no desktop app import), cloud bullet hierarchy fixes and Word XML repair. Source prompts and fictional fixtures are copied from the pinned HyPlug revision. Salary lines are filtered before parsing. AI replies must be bounded, structured JSON; parse fidelity and blind checks precede rendering, and blind output undergoes a direct-identity text/attribute/property sweep. Blind output always requires human review. This does not establish complete anonymisation, including indirect identity or embedded media.

The new callback boundary supports a trusted model policy and injected transport, reserves the full configured token ceiling, uses deterministic job/stage operation IDs, and settles verified usage before returning. No real model/prices or provider connections are configured. Unknown outcomes retain holds; no retries. The current implementation is an internal engine accepting extracted text, not a user-facing workflow. File extraction/OCR, storage binding, worker runtime, output persistence, provider adapters, API credentials and UI remain pending. Renderer template and normalizer/mask differences versus HyPlug still require comparison; the existing cloud template is deliberately retained. No production deployment.

Tests include fictional parse/blind responses with real Node DOCX generation, budget boundary and invalid responses. Existing desktop CI installs Node and adm-zip. Production sandbox limits, real Word visual checks, model price approval and human review are required before enabling routes.

## Implementation review
Reject non-finite JSON numbers (including exponent overflow), require the repaired blind CV to retain its role/bullet-group shape, and check the rendered blind output against both raw parsed and normalized candidate identities. Added a split-run/relationship identity regression fixture. This is a static review with targeted tests authored, not a completed security assessment.
