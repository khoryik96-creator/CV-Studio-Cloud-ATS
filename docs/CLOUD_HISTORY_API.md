# Persistent owner-scoped history
Authenticated GET /api/jobs and /api/documents expose bounded, cursor-paginated metadata for the active owner. Document history includes uploaded documents that have not been submitted; CV job history includes formatting/blinding only, and a flag indicating output metadata exists. Owner and tenant come from the session and active database account, not request parameters. Existing RLS, no-store and preview/download checks remain authoritative. No filenames, candidate text, hashes, credentials, reservation IDs, source file downloads or idempotency keys are returned. Cursor lookup is itself owner-scoped; no offset paging. No automatic resubmission, deletion or cancellation. The listing is not a snapshot and output availability is metadata, not proof of file integrity. UI history/recovery, durable upload intent, retention and reconciliation remain pending. CI fixtures use fictional records only.
