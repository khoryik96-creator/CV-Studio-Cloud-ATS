# Synthetic staging composition
This explicit composition connects the original CV Studio staging shell, authenticated routes, PostgreSQL metadata, private storage, bounded worker, synthetic completion and real Word renderer. There is no public worker trigger or live provider transport. The caller must create a disposable isolated database and private volume and supply a trusted owner roster. Only a reserved .test origin is accepted. The supplied fictional fixture is checked at the prepared-source boundary. Blinding, arbitrary documents, OCR, batch and remaining modules are not supported by this fixture transport. No real customer data or credentials.

CI exercises actual login, original shell delivery, cross-tenant checks, upload, queue, one worker tick, persisted output, Word XML and sign-out through Flask's test client. This is not a real browser, container deployment or production readiness result. Real provider secret injection, worker process isolation, account provisioning, production role grants and browser verification remain release gates. The default app stays health-only.
