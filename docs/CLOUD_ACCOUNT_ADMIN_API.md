# Account administration HTTP boundary
Optional owner/admin-only account listing and role/status/session-revocation operations. Authenticated principal, exact-origin CSRF, fixed action allowlist, canonical decimal credential revisions, and existing database authorization and transactional audit. No caller-selected tenant, raw password/hash exposure, account deletion or owner changes. Account creation and password reset intentionally remain internal pending secure onboarding and forced password-change design. Mock API and disposable PostgreSQL HTTP integration tests added. No production mounting or browser account-management panel.
