# Account activation page
Standalone opt-in /activate page, only registered with the redemption service. Manual entry of one-time code and recipient-chosen matching password. No named form inputs, no URL tokens, no browser storage, no inline scripts, CSP denies form fallback and framing, no automatic sign-in or retry. Clears inputs on submission/navigation, rejects late results. No email delivery, issuance UI or real-account enablement; trusted secure out-of-band delivery remains required. Integrated onboarding and usage stacks on master; combined CI required. Actual browser activation validation pending.
