# Consolidated account and history controls
Combines the account service/API and history UI with merged settings, batch and preview. Optional user panel is mounted only with the lifecycle endpoints, and only visible for an authenticated owner/admin. Explicit confirmation and revision fencing; refresh after writes or uncertainty. No self-modification, owner management, account creation or password reset in the UI. No real credentials or production deployment. Combined markup and JS permission tests; expanded synthetic Chromium history login/download test. Actual account UI browser interaction and secure onboarding remain pending.
