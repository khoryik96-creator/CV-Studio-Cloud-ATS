# Optional redemption HTTP boundary and expired invitation reissue
One-time challenges can be redeemed through an exact-origin, bounded POST body. Source and token-specific rate limits share the established persistent attempt store using isolated bucket namespaces. No session is automatically created and no raw token/password is returned. Invitation reissue is internal, limited to the existing inactive pending invitation and version, rotates token and credential version, and records a non-secret audit event. Ordinary account lifecycle actions cannot reactivate or mutate pending invitations. No email delivery, browser activation form, cancellation or cleanup of abandoned invitations, production DB roles or reverse-proxy trust configuration. The endpoint is opt-in and not mounted in production. Tests cover rate limiting, origin, malformed input, replay and reissue. Migration 010 is edited on this unmerged stack; never change an applied production migration.
