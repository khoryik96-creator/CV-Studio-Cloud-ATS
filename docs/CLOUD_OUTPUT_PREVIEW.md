# Output preview
Read-only literal paragraph preview from the same immutable verified DOCX returned by the authenticated download service. No source document or provider intermediate JSON is returned. Review-required outputs require explicit acknowledgement before preview; blinded outputs retain review status. Browser uses textContent only, clears on logout/new submission, and never executes document markup. Bounded output size and paragraph counts; errors fail closed. This is an initial final-output text preview, not the original rich structured preview or visual Word layout. Full visual fidelity, paragraph styling, edit/undo and browser verification remain pending. No extra AI call or data copy in the database.
