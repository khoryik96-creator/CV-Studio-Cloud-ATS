# M3 Company Profile
Pure source-grounded briefing contract, inspired by the legacy Company Profile focus/tone/length controls. Bounded source excerpts, stable IDs, dates, claim sections and exact evidence quotes. Unknown IDs, fabricated quotes, duplicate claims and empty reports are rejected; source metadata is returned from the caller rather than generated by the model. Review remains mandatory. Quotes do not guarantee entailment, authenticity, freshness or correct company identity. No URL fetching, live research, AI invocation, persistence or API yet. Safe retrieval with redirect/SSRF controls, verification, citation UI and provider/job integration are subsequent tasks.
Review: reject duplicate evidence and non-string source metadata. No external fetching or automatic assertion of factual accuracy.
