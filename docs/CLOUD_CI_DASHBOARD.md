# GitHub CI progress dashboard
The read-only dashboard summarizes open PR exact-head runs for the three known cloud/regression workflows. It runs when those workflows complete and can be run manually. No checkout, PR code execution, repository writes, deployments, or separate external credentials. It reports a snapshot in the Actions run summary, not a live chat notification or authoritative merge gate.

Optional 15-minute polling: after this workflow lands on the repository default branch, an operator may create a repository Actions variable CVCLOUD_CI_POLL with value true in Settings > Secrets and variables > Actions > Variables. It is disabled by default to avoid unexpected private-repository Actions usage. Scheduled runs can be delayed by GitHub; check the available minutes before enabling. Remove or set the variable false to disable scheduled polling. Event-based summaries and manual runs remain available. The existing hourly ChatGPT automation handles review and development separately.
