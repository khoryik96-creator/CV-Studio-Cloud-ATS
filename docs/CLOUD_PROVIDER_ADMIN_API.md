# Provider administration boundary
Opt-in authenticated configuration status/catalogue, replace/rotate and disable endpoints. Existing secure session and exact-origin CSRF checks; owner/admin only, actual database role rechecked by the existing provider service. No plaintext credential read endpoint, custom URLs, prices or paid test requests. Configuration revisions are canonical decimal strings to avoid JavaScript bigint precision loss. No tenant ID accepted from the browser. Status and errors are redacted; global no-store headers apply. Configure is a full replacement with optimistic revision fencing, not a patch. Disable cannot revoke an already in-flight provider call. Unit tests use a mock service; existing PostgreSQL tests cover actual RLS, encrypted storage and role/rotation fencing. Production DB/keyring segregation, audit history, browser settings UI and actual integrated admin API DB test remain pending. Default app and synthetic staging do not mount this service.
