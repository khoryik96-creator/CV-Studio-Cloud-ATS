# Interactive synthetic-only staging
Use a disposable local Docker host, never the shared VPS or a production DB. Run `sh cloud/deploy/interactive-smoke.sh` for a real HTTPS, PostgreSQL, session, automatic worker, preview, and Word-output smoke test. No external runtime network, no DB ports, no live AI or JobAdder calls. The smoke test recreates its containers, verifies that job history, preview, and Word downloads survive, and removes its unique project's volumes on exit.

For private manual use, start a distinct project with `docker compose -p cvcloud-local-fixture -f cloud/deploy/compose.interactive.yaml up --build -d`. Port 443 on localhost must be free; add cv.example.test to the local hosts file pointing at 127.0.0.1. Export the local synthetic certificate using `docker compose -p cvcloud-local-fixture -f cloud/deploy/compose.interactive.yaml cp web:/tmp/cvcloud.crt ./cvcloud-local.crt`; trust only this certificate for the local test origin in a disposable browser profile, never bypass TLS checks. It changes when the web process restarts. Open https://cv.example.test/cloud-ui with organisation fictional, email synthetic@example.test and password fictional-staging-only-123. Only the bundled tests/fixtures/cloud_cv_source.txt is accepted; do not upload candidate data. Format the fixture to test the existing interface. Blinding and other modules are not proven by this fixture yet. The development TLS server is explicitly not production infrastructure; /readyz stays 503.

Named DB and private file volumes survive container recreation. Initialization commits the role, migrations, accounts, and marker together, so interrupted initialization can be retried. The seed refuses unmarked schemas or changed migration signatures. Use a new disposable project for changed migrations. Stop and remove only this project's synthetic volumes with `docker compose -p cvcloud-local-fixture -f cloud/deploy/compose.interactive.yaml down --volumes`. Runtime uses a separate non-superuser DB role with existing test grants, not final production least privilege. Worker launches bounded subprocess rounds and relies on fenced expiry recovery; production isolation, hard cancellation of all arbitrary descendants, browser test in containers, and six-module coverage remain gates.
